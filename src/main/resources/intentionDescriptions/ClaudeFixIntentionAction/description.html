Sends the IDE-detected error or warning at the caret to Claude and offers the proposed fix in a side-by-side diff. Works on any inspection produced by IntelliJ — compiler errors, linter warnings, code-style issues — across all supported languages.

The selected line(s) plus the inspection message are sent to the claude CLI. The replacement is shown in the standard diff viewer; accept to apply, cancel to discard.

Triggered via Alt+Enter when the caret is on a highlighted problem.
